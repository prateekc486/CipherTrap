━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: "How does encryption work?"
A: "We use AES-256-GCM with Argon2 key derivation. Each file 
   gets a random 12-byte nonce, making even identical files 
   produce different ciphertexts. We store the original SHA-256 
   hash to verify integrity on recovery."

Q: "Can you recover if vault is deleted?"
A: "Yes - in production, we'd sync to cloud storage (AWS S3). 
   The vault can be on a separate air-gapped network for 
   critical systems."

Q: "How is this different from regular backups?"
A: "Traditional backups need human action. CipherTrap runs 24/7, 
   detects attacks in seconds using honeyfiles, and restores 
   automatically - all encrypted and integrity-verified."

Q: "What about zero-day ransomware?"
A: "Honeyfiles catch ANYTHING that tries to encrypt files. 
   Behavioral analysis catches unknown attacks by detecting 
   entropy spikes, mass modifications, and unusual patterns."
